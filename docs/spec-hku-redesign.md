# 校园帮 CampusPal · 港大版重设计规格

日期：2026-11-01 ｜ 状态：已确认，进入实现

## 目标

把「通用校园跑腿平台」改造成有辨识度的「香港大学」场景作品，核心差异化是**学生卡名片**。

## 核心概念：学生卡 = 数字身份 + 信用

一张像真实港大学生证的精美卡片，作为产品灵魂视觉，三处出现：
1. 「我的卡」页 —— 完整大卡 + 信用档案（认证状态合一）
2. 大厅顶部 —— 当前用户迷你横卡
3. 任务详情 —— 发布者/接单者迷你卡（一眼看可信度）

卡面：校徽 + 校名、照片占位、姓名、学号、学院、有效期、信用区（等级徽章 + 星 + 完成单数 + 准时率）。

## 视觉主题

- 主色：港大深绿 `#0b4f3a`
- 辅助：暖金 `#c9a227`（信用/奖励）
- 背景：米白/浅灰绿，学院风、庄重
- 校徽：港大盾形徽章（简化 SVG）

## 页面结构（5 页）

1. 任务大厅（顶部迷你卡 + 任务列表）
2. 发布任务（表单 + 地图选点）
3. 我的订单（我发布/我接到的）
4. 我的卡（完整卡 + 信用档案 + 认证状态）
5. 管理端（学生卡审核 + 纠纷裁决）

## 地图

- Leaflet + OpenStreetMap，CDN 引入
- 中心：港大主校区 22.2840, 114.1363
- 用途：仅发布任务时选「取件地/送达地」+ 预设地标
- 任务卡片只显示地名，坐标存数据

## 数据模型调整

- User 加：`studentId`（学号）、`faculty`（学院）、`admitYear`（入学年份）
- Task 加：`fromLat/fromLng/toLat/toLng`（坐标）
- 场景：云杉大学 → 香港大学

## 保留项（差异化核心）

- 信用体系（客观履约画像）
- 资金托管（先付款、确认后结算、代买差额退款）
- 纠纷处理（申诉→暂停结算→管理员裁决）
- 多角色切换（学生/管理员）
- 认证：学信网学籍证明 → 港大学生卡认证（管理员审核）

## 技术

沿用 React + TypeScript + Vite，Leaflet 通过 CDN + useEffect 集成（不用 react-leaflet，避免额外依赖）。
